# Memory System

This project uses Obsidian as its memory system. The Obsidian vault at `C:\Users\toshi\OneDrive\Documents\Obsidian Vault` serves as your long-term knowledge base.

## How to use memory

1. **Read from memory** — When you need context about the project, the user's preferences, past decisions, or anything previously stored, search the Obsidian vault using the `obsidian-vault` MCP tools.
2. **Write to memory** — When you learn something important about the project, the user's preferences, architecture decisions, or anything worth remembering for future sessions, save it to the Obsidian vault.
3. **Session tracking** — When starting significant work, create a note in the vault documenting the current task. When finishing, update it with outcomes and decisions made.

## Tools available

- Use `obsidian-vault` MCP tools to read, search, and write notes in the vault
- Use the `obsidian` CLI directly (if enabled) for vault operations
- Use the `obsidian-cli` skill for structured vault interactions
